# Start here

Copy the prompt below into your own Claude.

- **Claude Code:** open this kit's folder in Claude Code, then paste the prompt.
- **claude.ai:** start a new chat, attach both `README.md` and `FOR-CLAUDE.md` (and later any file you pick), then paste the prompt.

```
I have a copy of a Claude starter kit. Help me take only the pieces I want.
1. Read FOR-CLAUDE.md and README.md in the kit. If you cannot open files on my computer, ask me
   to attach both.
2. Show me the menu in plain words, recommend where to start, and ask which pieces I want.
3. Set up only those, the way FOR-CLAUDE.md says for the setup I am in.
4. Before changing any instructions or settings I already have, show me the exact change and
   wait for my yes. Never overwrite an existing file without asking.
5. The hook is optional: explain what it does before offering to set it up.
6. When done, tell me what you set up, where, and one thing to try first.
```
